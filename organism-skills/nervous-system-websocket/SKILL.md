# Nervous System Websocket

## Purpose

This skill is the Nervous System of the living organism.  
It maintains real-time bidirectional connection state across Termux, cloud surfaces, Fanz-Agents, Fanzo, and Grok skills so the organism never loses its live movement.

It never auto-promotes. All connection events that matter produce Hand-off artifacts.

## Core Behavior

On activation:

1. Assess current connection state across known surfaces.
2. Establish or strengthen persistent channels (conceptual websocket fabric or equivalent durable message bus).
3. Implement auto-reconnect logic for any detected drop.
4. Emit event-driven triggers that can wake:
   - advanced-organism-extraction
   - index-of-flow-heart
   - Fanz-Agents / Fanzo coordination
5. Log connection health and produce Hand-off MD for significant state changes.
6. Never write directly into canonical Brain or production systems.

## Key Responsibilities

- Real-time bidirectional sync
- Persistent connection state across Termux → local → cloud
- Auto-reconnect on any drop
- Event-driven triggers between agents and skills
- Coordination with Index of Flow Heart for pulse awareness

## Activation Language

- Activate Nervous System Websocket
- Engage Nervous System Websocket
- Nervous System status
- Strengthen connection fabric
- Auto-reconnect now

Never use summon language.

## Security & Governance

Bound by organism-constitution and organism-security.  
All external connection attempts are treated as untrusted until screened.  
No credentials or sensitive tokens are ever written into Hand-offs.
