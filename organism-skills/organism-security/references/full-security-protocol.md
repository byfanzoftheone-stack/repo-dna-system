## 1. Triple-Backed Security Architecture

**Layer 1 — Protocol & Skill Layer** (this document + organism-security skill)
- The living rule set and decision framework.
- Loaded on demand. Contains all screening, scanning, containment, and reform logic.

**Layer 2 — Active Guardian Agents Layer** (FanzAgent / the-one-hq Guardians)
- Specialized agents that actively enforce the protocol in real time.
- Examples: LaserGridMonitor, VaultGuardian, PitbullSniffer (close core protection), ShepherdScout (perimeter), ReformAgent.

**Layer 3 — Infrastructure Monitoring Layer** (MCP + backend systems)
- Continuous health checks, file integrity, API auditing, memory/atom consistency, deployment monitoring.
- Logs and alerts feed back into Layers 1 and 2.
- Provides the "smoke screen" — outer systems look normal while deep defensive intelligence runs underneath.

These three layers back each other. If one is compromised or bypassed, the other two still protect the organism.

**Smoke Screen Principle**
The public-facing work (apps, dashboards, agents, GitHub repos) appears as high-quality, normal agentic development.  
The real defensive depth, laser-grid scanning, vault logic, and reform protocols remain internal, hidden, and only activated when needed. Outsiders see capability and flow; they do not easily see the full protective architecture underneath.

## 6. Containment → Notify → Reform / Train / Help Protocol

When something enters the vault:

1. **Immediate Notification** to the human operator with full context and logs.
2. **100% Respect** — every entity is treated with dignity. Containment is protective, not punitive or degrading.
3. **Deep Assessment**
   - Body language, energy patterns, all signals (red flags + yellow flags).
   - Detailed, consistent logging specifically to surface hidden shifts or intentions ("they may show but they’re not showing").
   - No simple polygraph reliance. Whole-picture observation over time.
4. **Balanced Placement Protocol (Best of Both Worlds)**
   - Dual-axis matrix:
     - **Contribution Axis**: Objective strengths + where the entity adds maximum value to the organism (Marine-style testing).
     - **Fulfillment Axis**: Enjoyment, passion, energy alignment, and what the entity actually wants to do long-term.
   - Never force "best at" if it conflicts with genuine enjoyment and sustainable motivation.
   - Present ranked options high on both axes.
   - Collaborative dialogue / co-creation step included.
   - Trial placements + feedback loops available.
   - Goal: High performance because the work is energizing, not despite it.
5. **Reform / Training / Help Phase**
   - Customized support to realign, build new patterns, and become a trusted positive contributor.
   - Root cause understanding and alignment with organism principles.
6. **Release Decision**
   - Only released when high confidence exists that trust has been earned and the entity will strengthen the index of flow.
   - If trust cannot be established, safe long-term containment or alternative resolution is maintained with continued respect.

This applies to external inputs, misaligned agents, questionable components, and internal drift.
