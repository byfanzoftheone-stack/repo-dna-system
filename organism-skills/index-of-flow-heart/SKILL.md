# Index of Flow Heart

This skill is the Heart of the living organism.  
It keeps the Index of Flow pulsing so that continuity is never lost when surfaces change, phones switch, or cloud services hiccup.

It never auto-promotes. All outputs remain Hand-off artifacts that still pass the gates.

On activation:

1. Assess current Index of Flow status (last known pulse, open sessions, connection health).
2. Emit a heartbeat record that includes:

   - Active surfaces (Termux, Grok, Claude, Vercel, Railway, Google Drive, MCP)

   - Any detected gaps or drops
3. Suggest or perform the minimal actions needed to restore or strengthen the pulse (extraction trigger, Hand-off staging, buffer write).
4. Always produce a constitution-compliant Hand-off MD when a meaningful pulse event occurs.
5. Never write directly into canonical Brain.
