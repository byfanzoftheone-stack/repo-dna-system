# Pre-Ambition Focus Cycle

Human operator protocol. Run before Skillz expansion, skill creation, or any ambitious implementation pass.

This is not agent activation. Agents wait. The operator sets the body first.

## Why it exists

Ambition is useful after it has a gate. Excitement that starts coding before inspection produces stale skills, over-claims, and skipped Hand-offs.

The cycle is the gate on the operator, the same way sandbox is the gate on agents.

## Naming (constitution-clean)

Use these names in skills, UI, and Hand-off MD:

- Pre-Ambition Focus Cycle (canonical)
- Gather-Release Breath (motion name)
- Warrior breath (allowed alias — discipline, not occult)

Do not use: ritual, invocation, summoning, spell, chi-magic, clearing spirits.

Tai chi here means slow, continuous motion timed to breath. Negative load means scattered attention, leftover frustration, and ungoverned excitement in the work area. Release means the operator puts that load down before touching code or skills.

## Cycle (3 rounds minimum)

Stand or sit with a long spine. Slow motion. No rush into the first keystroke.

### Gather (inhale)

1. Inhale through the nose.
2. Hands and torso move in a slow scoop — low to midline — as if collecting the leftover load in the room and in the chest.
3. Name the load silently in work terms: drift, leftover tab, unfinished idea, hype, fear of missing the build.
4. Do not start the task during gather.

### Hold (peak)

1. Brief pause at the top.
2. One sentence only: what is the single topic of this pass?
3. If more than one sentence appears, you are not ready. Another gather.

### Release (exhale)

1. Exhale through the mouth or nose, longer than the inhale.
2. Motion presses forward and down — set the collected load outside the work area.
3. Shoulders drop. Hands return to ready, not to the keyboard yet.

Repeat 3 rounds. On round 3 the topic sentence must be stable.

## After the cycle

Only then:

- Open the skill library inspection
- Touch code
- Draft a new skill
- Follow an exciting idea

If a new exciting idea arrives mid-work, pause and run one gather-release before switching topics. That is how ambition stays in line without killing drive.

## Agent behavior when the user is in-cycle

- Do not flood with extra proposals.
- Hold the topic sentence the user just locked.
- If the user dumps a burst of ideas, list them, then ask which one survived the cycle.
- Never skip inspection because the idea felt strong.

## Logging

Record in the Skillz pass output:

```
focus_cycle: run | skipped
rounds: N
topic_sentence: ...
post_cycle_ideas_parked: [ ... ]
```

Skipped cycles are findings, not moral failures. Note them and offer one round before continuing.
