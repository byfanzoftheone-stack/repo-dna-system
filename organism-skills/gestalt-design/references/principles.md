# Gestalt Principles Reference

## Prägnanz (Law of Simplicity / Good Figure)

The mind prefers the simplest, most stable, and most regular interpretation of what it sees.

**Design implication:** Reduce visual and structural complexity. Prefer clean order over decorative density. Complexity must be earned.

## Proximity

Elements that are close together are perceived as belonging to the same group.

**Design implication:** Group related controls, labels, and data tightly. Separate unrelated groups with clear space.

## Similarity

Elements that share visual properties (color, shape, size, style, weight) are seen as related.

**Design implication:** Use consistent visual treatment for the same type of information or action across the entire system.

## Continuity (Good Continuation)

The eye prefers continuous lines and smooth paths over abrupt breaks or jagged changes.

**Design implication:** Align elements along clear axes. Support natural scanning flow. Avoid broken visual paths.

## Closure

The mind completes incomplete shapes or patterns when enough structure is present.

**Design implication:** You can imply structure without drawing every detail. The brain will fill gaps if the pattern is strong.

## Figure-Ground

We automatically separate the main subject (figure) from the background (ground).

**Design implication:** Make primary content clearly stand out. Avoid multiple elements competing with equal visual weight.

## Common Fate

Elements that move or change together are perceived as belonging to the same group.

**Design implication:** Animate related items in coordinated ways. Use shared motion to reinforce relationships.

## Symmetry / Order

Symmetrical and orderly arrangements feel more complete and stable.

**Design implication:** Balanced, predictable layouts feel calmer and more trustworthy. Extreme asymmetry increases tension.

## Connectedness

Elements that are physically linked (lines, borders, shared containers) are seen as one unit.

**Design implication:** Use explicit visual connections when proximity alone is not enough to show relationships.

## Visual Hierarchy Techniques

| Technique | Purpose |
|---------|---------|
| Size | Larger elements attract more attention |
| Color & Contrast | High contrast or saturated color stands out |
| Typography | Weight and size create levels of importance |
| Spacing | More space increases perceived importance |
| Position | Top and center areas receive more attention |
| Depth / Elevation | Raised elements feel more primary |
| Alignment | Consistent structure supports scanning |

## Application Priority for THE ONE Organism

1. Current organism state and escalations must be immediately visible.
2. Governance actions and approval gates must be unmistakable.
3. Related information must be grouped; unrelated information must be separated.
4. Secondary and tertiary details should stay quiet until needed.
5. The overall structure of any interface should feel stable and ordered.
