# Gestalt Design

Apply Gestalt psychology principles, Prägnanz, and Visual Hierarchy to keep THE ONE organism interfaces clear, low-cognitive-load, and trustworthy.

## When to Activate

- Designing or reviewing any UI for the Warehouse, Echo Forge, Agentic City, Compadre, or organism dashboards
- User mentions visual clarity, simplicity, hierarchy, cognitive load, or Gestalt
- Building new panels, node canvases, status displays, or governance views
- Critiquing existing interfaces for noise, confusion, or overload

## Core Rule

If something requires significant mental effort to understand, it is not yet ready for the organism.

## Instructions

1. **Start with Prägnanz**
   - Prefer the simplest stable structure that still communicates the truth.
   - Remove visual noise before adding new features.
   - Ask: Does this reduce or increase cognitive load?

2. **Enforce Visual Hierarchy**
   - Establish clear primary, secondary, and tertiary levels.
   - Make the most important information (current state, escalations, required actions) immediately obvious.
   - Mute or hide lower-priority details by default.

3. **Apply Grouping Principles**
   - Use **Proximity** to group related items.
   - Use **Similarity** for consistent treatment of the same type of information or action.
   - Use **Connectedness** (lines, shared containers, borders) when relationships must be explicit.
   - Keep unrelated items clearly separated by space.

4. **Support Perception**
   - Maintain strong **Figure-Ground** separation so primary content stands out from background.
   - Support **Continuity** so the eye can move smoothly across the interface.
   - Prefer orderly, predictable layouts over decorative complexity.

5. **Progressive Disclosure**
   - Show only what is needed for the current task.
   - Hide advanced details, full history, and secondary controls until requested.
   - Never force the full complexity of the system onto the user at once.

6. **Review Checklist**
   When reviewing any interface, check:
   - Is the most important thing obvious within 1–2 seconds?
   - Are related items grouped and unrelated items separated?
   - Is there a clear hierarchy of importance?
   - Does the layout feel stable and ordered?
   - Can the user understand the current state without deep analysis?
